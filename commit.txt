refactor(readability): decompose engine paths, ukengine TUs, and macro interchange

## Why

- Apply the readability plan: named booleans and `static`/private helpers so intent is
  visible before mechanics, without changing observable behavior (preedit, commits,
  macros, charsets).
- Follow existing project style (e.g. `mactab.cpp`-style structure and Doxygen where
  already used in touched areas).

## What changed

### IBus engine and `UkEngine` surface

- `src/engine.cpp`: clearer dispatch for `ibus_unikey_engine_process_key_event` /
  preedit path; static predicate-style helpers where it reduced dense modifier/keyval
  conditions.
- `include/ukengine/engine/ukengine.h`: declarations aligned with refactored
  `UkEngine` implementation split.

### Core engine (`ukengine/`)

- `ukengine/engine/engine_components/diacritic_processing.cpp`: break up large `process*`
  methods; shared vowel/tone patterns use named guards and helpers where duplication
  was obvious.
- `ukengine/engine/engine_components/append.cpp`: structure `processAppend` and related
  append logic with clearer phases and locals.
- `ukengine/engine/engine_components/process_io.cpp`: decompose `UkEngine::process` and
  related output sequencing for easier review.

### I/O and charset

- `ukengine/core/byteio.cpp`: flatten `FileBIStream` multi-byte reads (`getNextW` /
  `getNextDW` / `peekNextW`) and clarify EOF predicates on `getNext`/`peekNext`.
- `ukengine/mapping/charset_components/charset_unicode.cpp`: extract
  `tryConsumeCStyleHexEscapeAfterBackslash` for `UnicodeCStringCharset::nextInput`
  (`\x` / `\X` hex escapes only; HTML `&#` / NCR paths unchanged).

### Macro table load/save

- `ukengine/mapping/macro_cache.cpp`: `tryLoad` / `persist` use phased `const bool`
  checks and single `fclose` on the cache file path where applicable.
- `ukengine/mapping/mactab.cpp`: `writeToFile`, `loadFromFile`,
  `decodeMacroKeyAndText` use explicit success flags (`textExportOk`, sidecar hydrate,
  UTF-8 upgrade branch, decoded key/text pairs).
- `ukengine/mapping/text_macro_format.cpp`: named flags for open and header reads on
  import/export.

### Setup macro interchange

- `setup/macro_file_io.cpp`: `importArgumentsValid` / `exportArgumentsValid` for early
  `GError` paths.
- `setup/macro_handler_csv.cpp`: `delimited_row_looks_like_macro_header`; CSV parse/fini
  success locals; repair accidental stray `§` in source after `return FALSE`.
- `setup/macro_handler_plist.cpp`: named booleans around plist parse and root-shape
  handling.
