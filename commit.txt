fix(build,ukengine): align CMake with charset/engine split; macro title-case expansion

## Why

- `ukengine/CMakeLists.txt` still referenced removed monoliths `mapping/charset.cpp` and
  `engine/ukengine.cpp`, breaking configuration. The real sources live under
  `mapping/charset_components/` and `engine/engine_components/`.
- Mixed-case macro triggers (e.g. typing `Hn` for a fold key `hn`) fell through to
  `VnCaseNoChange`, so expansions stayed lower case (`hà nội`) while all-caps triggers
  (`HN` → `HÀ NỘI`) still worked.

## What changed

### Build (`ukengine/CMakeLists.txt`)

- Replace `mapping/charset.cpp` with the nine `mapping/charset_components/*.cpp` translation units.
- Replace `engine/ukengine.cpp` with all `engine/engine_components/*.cpp`,
  `table_components/*.cpp`, and `engine/unikey.cpp`.
- Add `target_include_directories` entries for `mapping/` and `engine/` so includes like
  `charset_components/charset_internal.h` and `engine_components/engine_internal.h` resolve.

### Macros (`ukengine/engine/engine_components/macro.cpp`)

- Add `VnCaseTitle`: when the trigger starts with an uppercase Vietnamese letter and any
  following key is lowercase, normalize expansion to lower then capitalize the first letter
  of each ASCII-space–delimited word (e.g. `hà nội` → `Hà Nội` for trigger `Hn`).
- Keep `VnCaseAllCapital` / `VnCaseAllSmall` behavior for uniform triggers.

### Documentation (`TECHNICAL_NOTE.md`)

- Document charset and engine breakup, CMake source list, and include-path rationale (§11).
- Fix stray typo in table of contents; extend TOC for §11.1.x; Vietnamese summary tweak for
  `engine_components/`.

## Files touched

- `ukengine/CMakeLists.txt`
- `ukengine/engine/engine_components/macro.cpp`
- `TECHNICAL_NOTE.md`
- `commit.txt`
