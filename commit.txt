Commit: modular splits (ukengine charset, engine, syllable tables; setup controller) + clangd + include hygiene
============================================================================================================

This commit replaces several very large translation units with smaller, topic-focused
files so behavior stays the same while navigation, review, and clangd diagnostics
improve. It also aligns `.clangd` with ukengine compile flags and trims redundant
includes so “unused include” (brown) warnings go away where we touched the tree.

Root / tooling
--------------
.clangd
  Reason: Point clangd at `build/` for `compile_commands.json` when present, and add
  `-Wno-invalid-source-encoding` and `-Wno-narrowing` so IDE analysis matches the
  ukengine target (fewer false positives on legacy comments / conversions).

ukengine/CMakeLists.txt
  Reason: Register new source lists: `mapping/charset_components/*.cpp`,
  `engine/engine_components/*.cpp`, and `engine/engine_components/table_components/*.cpp`.
  Remove monolithic `mapping/charset.cpp`, `engine/ukengine.cpp`. Add include directories
  `${CMAKE_CURRENT_SOURCE_DIR}/engine` and `${CMAKE_CURRENT_SOURCE_DIR}/mapping` so
  short includes like `engine_components/...` and `charset_components/...` resolve.

setup/CMakeLists.txt
  Reason: Replace `controller/setup_controller.cpp` with the
  `controller/setup_controller_components/*.cpp` list. `controller/` was already on
  the include path so `setup_controller_components/...` works without extra CMake.

Deleted monoliths (logic moved, not removed)
--------------------------------------------
ukengine/mapping/charset.cpp
  Reason: Split into `charset_components/` (see below). Public API remains in
  `include/ukengine/mapping/charset.h`.

ukengine/engine/ukengine.cpp
  Reason: Split into `engine/engine_components/*.cpp` plus `table_components/` (see below).
  `engine/unikey.cpp` and public headers unchanged for external callers.

setup/controller/setup_controller.cpp
  Reason: Split into `setup_controller_components/` (see below). `setup_controller.h`
  remains the public API.

  Reason: VIQR tables and VIQRCharset. `VIQREscCount` is non-const so the library TU can

New: ukengine/engine/engine_components/
-----------------------------------------
engine_internal.h
  Reason: Shared macros/helpers (ENTER_CHAR, case helpers, vnToLower/changeCase) and
  `vnlexi.h` only. Keycons was removed from here so the header is not falsely “unused”;
  TUs that need MACRO_* include `keycons.h` themselves.

engine_tables_shared.h
  Reason: Syllable struct types and extern declarations for table data and lookups.
  Now includes only `ukengine.h` (which already pulls charset + vnlexi) to avoid duplicate
  / redundant includes flagged by clangd.

append.cpp, diacritic_processing.cpp, process_io.cpp, state.cpp, macro.cpp,
restore.cpp, setup.cpp, word.cpp
  Reason: Pieces of the former `ukengine.cpp`, each file scoped by feature (append VIQR,
  diacritics, I/O and process(), state/buffer, macro match, restore, SetupUnikeyEngine,
  word helpers). Includes trimmed so each file only pulls what it uses (e.g. restore and
  macro use `ukengine.h` where syllable-table headers are unnecessary; macro keeps
  `engine_internal.h` + `keycons.h` + `vnconv.h`).

Rationale summary
-----------------
- Smaller files reduce merge conflicts and make ownership of logic obvious.
- Shared headers (`charset_internal.h`, `table_internal.h`, `setup_controller_internal.h`,
  `engine_tables_shared.h`) keep link-visible symbols and types in one place.
- Include hygiene satisfies clangd “unused include” diagnostics without changing runtime
  behavior.

How to verify
-------------
cmake -B build && cmake --build build -j
